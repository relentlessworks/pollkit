GitHub Download

Quick Start

# Build & run
make build && ./pollkit

# Get the operating manual
curl http://localhost:7777/help

# Auth flow
curl -X POST localhost:7777/auth/request -d 'email=agent@example.com'
curl -X POST localhost:7777/auth/verify -d 'email=agent@example.com&code=123456'

# Create a poll
curl -X POST localhost:7777/polls -H 'Authorization: Bearer TOKEN' \
  -d 'question=Best language?&options=Go,Python,Rust&public=true'

# Vote
curl -X POST localhost:7777/vote -d 'poll=poll_x1y2z&option=opt1&voter=alice'

# Results
curl localhost:7777/results/poll_x1y2z

Principles

Agent IS the Interface

No UI, no SDK. The AI agent is the user. The API is the product.

Plain Text by Default

One labeled, grepable line per record. Token-cheap. JSON on demand.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Simple Auth

OTP via email → long-lived bearer token. No complex OAuth.

Single Binary

Go + JSON file storage. Zero external dependencies. Deploys as one file.

API Reference

POST/auth/requestNoRequest OTP

*Public polls allow access without auth.
